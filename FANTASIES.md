## 🗺️ Option B — Embed external maps in notes
Allow users to paste a Google Maps, Felt, or similar map URL into a note and have it render as an interactive iframe embed — similar to how Notion embeds Google Maps links. Could also support "mini map previews" when a Google Maps link is detected in text.

## 📱 Social Platform Integrations
Let users pull in recommendations, reviews, and travel content from the platforms they already use — especially relevant for Chinese/Asian users.

**China**
| Platform | What for | API access |
|---|---|---|
| 小红书 Xiaohongshu | Travel inspo, restaurant recs, lifestyle content | No public API — requires business partnership or unofficial methods |
| 大众点评 Dianping | Restaurant/business reviews & ratings (China's Yelp) | Restricted — requires Meituan partnership |
| 马蜂窝 Mafengwo | Travel itineraries, trip notes, destination guides | Partial API available |
| 携程 Ctrip / Trip.com | Hotel/attraction reviews + booking data | API via partnership |
| 抖音 Douyin | Short video travel content | No public API |

**Japan**
| Platform | What for | API access |
|---|---|---|
| 食べログ Tabelog | Restaurant reviews — the authority in Japan | Limited API |
| じゃらん Jalan | Travel & hotel recommendations | API available |

**Korea**
| Platform | What for | API access |
|---|---|---|
| Naver Map | Places, reviews — Google Maps equivalent in Korea | API available |
| Kakao Map | Places, younger demographic | API available |

**Southeast Asia + Global**
| Platform | What for | API access |
|---|---|---|
| Klook | Asia travel experiences & activities | API available |
| TripAdvisor | Global reviews & attraction data | Content API (free tier) |
| Foursquare | Places data & tips | Free tier API |
| Instagram | Travel content globally | Basic Display API (limited) |

**Ideas for how this could work in Flappit:**
- "Import from Xiaohongshu" — paste a post URL, extract the location + note content
- Dianping restaurant card embedded in a note (name, rating, address, auto-pin on map)
- Mafengwo itinerary import — pull an existing trip into Flappit as notes + pins

## 🎭 Celebrity / Anime / Movie Crush Mode
Users name their celebrity, anime character, or film/show.
Recommended places adjust to fan spots — filming locations, themed cafés, merch stores, pilgrimage sites.
Example: "I love Spirited Away" → Jiufen, Taiwan + Dogo Onsen + Studio Ghibli Museum

---

## 🍜 Calorie Tracker
Estimate calories **in** based on signature dishes of restaurants in the itinerary.
Estimate calories **out** based on daily walking distance + activities.
Show a daily balance so health-conscious travellers can plan accordingly.

---

## 🏮 Traditional Mode vs Tourist Mode
- **Traditional** — blend into local life: neighbourhood markets, local eateries, public transport, residential areas
- **Tourist** — iconic sights, cultural highlights, popular food spots, curated experiences
Users can toggle or mix per day.

---

## ✈️ Pre-Departure Checklist
Before they fly, remind users what they need:
- Key local phrases
- Must-have local apps (e.g. Alipay, Grab, Naver Maps)
- Currency & exchange tips
- SIM card or eSIM recommendation
- Visa requirements (based on user's nationality, if provided)
